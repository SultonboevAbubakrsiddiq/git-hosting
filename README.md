# O'yinlar Olami 2026

Bootstrap yordamida yaratilgan amaliy vazifa (o'quv loyihasi). Sayt Bootstrap komponentlarini amalda qo'llashni ko'rsatadi: navbar, header, kartalar, forma va footer.

🔗 **Jonli sayt:** [oyinlarolami2026.netlify.app](https://oyinlarolami2026.netlify.app/)

---

## 📌 Loyiha haqida

Bu sahifa Bootstrap framework'ining asosiy komponentlarini o'rganish maqsadida tayyorlangan. Sahifada o'yinlar va mashhur brendlar haqida qisqa ma'lumotlar kartalar ko'rinishida berilgan.

## 🧩 Sahifa bo'limlari

| Bo'lim | Tavsif |
|--------|--------|
| **Navbar** | Navigatsiya paneli va qidiruv maydoni |
| **Header** | Katta banner rasm va sarlavha |
| **O'yinlar** | Minecraft va PUBG Mobile logotiplari |
| **Mahsulot kartalari** | Coca Cola, KFC va BMW haqida qisqa ma'lumot va tugmalar |
| **Forma** | Email, parol va "Check me out" belgisi bilan kirish formasi |
| **Footer** | Sahifaning pastki qismi |

## 🛠 Ishlatilgan texnologiyalar

- **HTML5**
- **CSS3**
- **Bootstrap** (grid, navbar, card, form, button komponentlari)
- **Netlify** (hosting)
